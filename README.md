# Mixed AI Models

Practice notebooks covering machine learning on tables and deep learning on images.

## Notebooks

- `01_Cell_Phone_Price_Analysis_Answer_ready.ipynb`: analyse a phone dataset and predict prices with linear models, k-NN, SVR, random forest, gradient boosting and XGBoost, tuned with grid search
- `ResNet-50_image_classification.ipynb` and `Transfer_Learning/`: image classification and transfer learning with ResNet-50
- `AI_track-completed_to_deployed.ipynb`: an image model in MindSpore, from data augmentation and training to evaluation and deployment

## Built with

Python, pandas, scikit-learn, XGBoost, PyTorch, MindSpore.

## How to run

Open the notebook in Jupyter (or VS Code) and run the cells from top to bottom.
